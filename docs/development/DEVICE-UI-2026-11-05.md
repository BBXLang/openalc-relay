# 小米手机 UI 验证记录

日期：2026-11-05（Asia/Singapore）。这份记录区分最初受系统限制的安装尝试、用户在手机确认后的成功安装、以及随后进行的有限界面与合成数据验证。

这是先前的界面检查记录；同日后续已完成[合成同步到浏览器的真机验证](DEVICE-SYNC-2026-11-05.md)。下表的“未测试”仅指本次界面检查时的范围。

| 项目 | 观察 |
| --- | --- |
| 机型 | Xiaomi `25113PN0EC`（设备代号 `pudding`） |
| 系统 build | Android 17 / API 37；`OS4.0.5.0.XPCCNXM`，完整 build fingerprint 保存在本机忽略证据文件 |
| APK target SDK | 36 |
| 连接与安装方式 | 有线 ADB，设备已授权调试；用户在手机端确认 USB 安装后，用 `adb install -r` 安装本机新签名 debug APK |
| 既有应用 | 安装前 `pm path org.openalc.relay.poc` 无结果，本机所连这台手机没有该包 |
| 安装结果 | 最初两次返回 `INSTALL_FAILED_USER_RESTRICTED`；手机确认后安装成功，更新版也成功覆盖。应用启动后 `MainActivity` 位于前台 |
| 权限 | `RECEIVE_SMS: granted=false`；没有请求短信接收权限 |
| 网络 | 未测试 collector、`adb reverse`、WorkManager 上传或公网连接 |
| 样本数 | 通过应用菜单按钮保存 2 条固定格式合成 fixture；真实短信 0；核查空收件箱、菜单和两条事件列表截图 |
| 进程重启 | `am force-stop` 后重新启动应用，两条合成事件仍从本地显示；这不是设备重启或后台调度验证 |
