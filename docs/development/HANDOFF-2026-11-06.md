## 三、踩坑点（全部实测，恢复时必读）

1. **本宿主跑 `scripts/test-web-poc.ps1` 必须用 pwsh 7**：powershell.exe 5.1 两次失败——缺 `System.Net.Http` 程序集类型、JDK 25 stderr 警告被 `$ErrorActionPreference='Stop'` 包成 NativeCommandError。CI（windows-latest）不受影响。
2. **vite preview 默认只绑 IPv6 `::1`**：`http://127.0.0.1:PORT` 拒连导致 Playwright 全挂；必须加 `--host 127.0.0.1`。
3. **Git Bash 调 adb 的路径转义**：`/data/local/tmp` 会被 MSYS 转成 `C:/Git/data/...`；设备端路径要写 `//data/local/tmp`（双斜杠）。
4. **ab7b1729（Pro Max）是多显示屏设备**：`adb shell screencap` 出警告且需设备端中转（screencap 到 /data 再 pull）。
5. **HyperOS USB 安装确认**：`install -r` 可能报 `INSTALL_FAILED_USER_RESTRICTED`，等 15 秒重试一次；旧签名包冲突需先 `uninstall` 自己的旧包（包名 `org.openalc.relay.poc`）。
6. **Gradle 需显式三环境变量**：`JAVA_HOME=bin/android-tooling/jdk-25.0.5.0.2+1`、`GRADLE_USER_HOME=bin/android-tooling/gradle-home`、`ANDROID_HOME=bin/android-tooling/sdk`（缺 ANDROID_HOME 报 SDK location not found）。
7. **Playwright 全链（chain.spec）需要 collector+播种**：直接跑会失败；formal-nav.spec 可用 `vite preview --host 127.0.0.1` 单独跑（18 用例）。全链播种手法见 `scripts/test-android-poc.ps1`（gradle `pocHarness`）。
8. **Compose 滑块抖动根因**（已修）：松手时先清零拖拽偏移→渲染一帧跳回旧页→再从旧值动画。教训：动画起点必须 snapTo 当前视觉位置（`ChannelShiftState` 现实现）。ArkUI 同类隐患是 translate 数字 vp 与 `'50%'` 字符串单位混用（已修）。
9. **Android 抽屉宽度**：M3 无 `ModalDrawerSheet` 包裹时自绘列也要显式限宽；默认 360dp 在手机上超四分之三屏。
10. **`devecocli` 位置**：不在 `bin/harmony-tooling/` 根，而在其 `node_modules/.bin/`。
11. **Go 1.25.0 可编译本仓库**（go.mod 写 1.26.0 但实际可构建）；`-race` 本机不可用（CGO 缺 gcc），race 留给 Linux CI。
